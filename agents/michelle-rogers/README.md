# Michelle Rogers Executive Agent

A locally‑hosted AI executive designed to act as a stand‑in for the user in business strategy, fundraising, and relationship management.

## Features (planned / stubbed)
- Persistent state stored in Supabase (contacts, curriculum, funding pipeline).
- Knowledge‑base built from the **Michelle Rogers Executive Intelligence Manual** (30 departments).
- Integrated Gmail / Google Calendar / Drive adapters (OAuth required).
- Voice interaction hooks (speech‑to‑text, text‑to‑speech).
- Business‑focused skills: law, economics, psychology, investing, social engineering, management.
- Command‑center UI (React + Vite) for dashboard and task management.

The repository will host both source code and research artifacts.
